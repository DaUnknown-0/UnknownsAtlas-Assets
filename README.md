# UnknownsAtlas-Assets

Map images for **Unknown's Atlas**: the floor, object and console atlases of the built-in maps (Vesper Museum,
Forest Station, Moonlight Carnival) and the pictures of the custom minigames and eject scenes.

They are not shipped inside `UnknownsAtlas.dll` any more. The mod downloads them automatically into
`BepInEx/atlas-assets` and checks every file against the size and SHA-256 in its built-in catalog: at every start, and
again whenever a file in that folder is changed, deleted or replaced. Missing or wrong files are downloaded again.
`catalog.json` lists the same data for reference.

- `files/*.atx`: pre-compressed textures (DXT1/DXT5 with mipmaps, raw deflate), made by `tools/pack_textures.py`.
- `files/task_*.png`, `files/task_eject_*.jpg`: minigame and eject scene pictures.
- Each tag (`v1`, `v2`, ...) is one set of images; a build of the mod always reads from the tag in its catalog.

Generated by `tools/build_assets_repo.py` in the UnknownsAtlas repository. Licensed under GPL-3.0-or-later like the mod.
